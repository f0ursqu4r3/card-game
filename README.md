# Retro Card Table

A 2D tabletop card deck simulator with retro-inspired graphics, built with Python and Pygame-CE.

## Description

Retro Card Table is a versatile card game simulator that lets you manipulate virtual playing cards just like you would on a real table. Features pixel art graphics and an intuitive interface inspired by classic computer games.

## Features

- 🎴 Standard 52-card deck simulation
- 🖱️ Drag-and-drop card manipulation
- 🔄 Shuffle, deal, and stack cards
- 🎨 Retro pixel art aesthetics
- 🎮 Multiple card game layouts
- 💾 Save and load game states

## Requirements

- Python 3.8+
- pygame-ce

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/retro-card-table

# Install dependencies
pip install pygame-ce
```

## Usage

```bash
python main.py
```

## Controls

- Left Click: Select/Drag cards
- Right Click: Flip cards
- Space: Shuffle deck
- D: Deal cards
- S: Save game state
- L: Load game state
